NK GTA credits
==============

Map data
--------
OpenStreetMap
  Streets, buildings, parks, shops, U-Bahn and bus stops.
  © OpenStreetMap contributors, licensed under the Open Database License (ODbL).
  https://www.openstreetmap.org/copyright

OpenStreetMap tiles (tile.openstreetmap.org)
  The background map in the area picker (pick.html).
  © OpenStreetMap contributors. Thanks to the OpenStreetMap Foundation for the tile service.

Overpass API
  OSM data is fetched through these public Overpass instances:
  - overpass-api.de
  - overpass.private.coffee
  - overpass.kumi.systems

Terrain
-------
Berlin elevation model ATKIS DGM1
  Geoportal Berlin / Senatsverwaltung für Stadtentwicklung, Bauen und Wohnen.
  Datenlizenz Deutschland – Zero – Version 2.0 (DL-DE-Zero-2.0).
  https://gdi.berlin.de/data/dgm1/atom/
